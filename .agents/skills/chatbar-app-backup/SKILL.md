# ChatBar Full App Backup

Source paths below are relative to app/app/src/main/java/com/example/chatbar/.

## Owners

- Entry: ui/manage/GlobalSettingsScreen.kt 数据迁移; existing save/discard navigation guard applies. AppBackupHost.kt owns secure input, SAF, scope/mode/preview confirmation, progress/cancel, and close/reopen. Default mode is REPLACE_ALL; summaries with scope and all incremental modes require preview before confirmation. Only legacy full backups without scope bypass merge preview. AppBackupSelectionScreen.kt is a full-window, lazy overview → settings/card-session chooser with search, scoped select/clear, light preset, and fixed debounced size footer. Character headers use a tinted surface, explicit 角色卡 label and icon; session children use an inset rail, 会话 label and chat icon.
- Operation: domain/backup/AppBackupService.kt application-owned job/StateFlow. Flush latest Studio draft before snapshot; every restore preview holds maintenance lease through confirmation, and pending restore keeps it until process exit. Changing mode/dismissing preview releases admission and deletes only generated staging. Password stays in volatile operation memory only.
- Scope: BackupDataRegistry.kt owns entitySerializers (40 current/legacy JSON types), six media roots, tag.sqlite/catalog.json, four portable preferences and resource fields. Export directly visits registered singleton/collection paths; never enumerates filesDir siblings. New stores need registry plus selection owner/dependency mapping. Inventory/counting, archive creation and export validation use this selection; import validates every incoming entity type strictly. Audited owners/scope: doc/app_backup_data_scope.md.
- Selection: BackupExportSelection.kt owns setting options, card/session dependencies, streaming catalog, projected fields and deduplicated size estimates. Catalog reads persistent JSON directly; final plan is reread under maintenance after flushing drafts. Estimates include selected JSON, referenced original assets and separately selected archive packages; mark unknown content-URI sizes and compression variance. No broad media sweep in service exports.
- Format: AppBackupCodec.kt, BackupArchive.kt, BackupJsonStream.kt, BackupTextIO.kt. Fixed CBBACKUP head + bounded envelope + ZIP: files/, preferences.json, inventory.jsonl, manifest.json. New selected exports use envelope/manifest v2 with compact scope; v1 remains readable and legacy engine fixtures retain v1. Old clients reject envelope v2 with upgrade notice. Original media copied; inventory streams size/SHA-256 records. CRC/duplicates/path containment/version/space checks run before accepting staging.
- Crypto: Tink Android 1.23.0 AES256_GCM_HKDF_1MB, random keyset wrapped using PBKDF2-HMAC-SHA256/600000 + AES-GCM. Envelope authenticates payload. NovelAI/Fish readForBackup distinguishes absent credentials from undecryptable ciphertext; destination Keystore reencrypts on restore.
- Consistency: LocalDataMaintenance.kt counts access across coroutines/threads, waits for a quiet window, then excludes new writers. Protect complete multi-store operations and queued writes. AI lease owns admission; local transfers use LocalDataTransferForegroundService.runProtected independently of network checks.
- Studio history image multi-delete holds admission across selected-record reads, media staging, applyEntityChanges, rollback and cleanup; backup cannot snapshot between individual image/JSON mutations.
- Recovery: BackupPreparedSeal.kt, BackupRestoreTransaction.kt, AppBackupBootstrap.kt. noBackupFilesDir/app-backup owns incoming/ (validated archive), prepared/ (complete prepared tree), rollback/, restore.json, and interrupted-operation progress. Journal stageDirectory chooses incoming only for legacy full replacement without scope; scoped replacement/incremental modes use prepared. Old journals default prepared. Seal mapped bytes and sync files/directories before PREPARED.
- Merge: BackupMergeEngine.kt plans replacement/merge, BackupMergeCatalog.kt streams identifiers, BackupMergeIdentity.kt owns typed ID/key maps, BackupMergeMemory.kt spools one node at a time and rebuilds parent proofs. BackupRetainedMedia.kt spools unselected local media fields through BackupJsonStream value observers/replacements without reading whole messages/history. Feature-specific ownership, matching and legacy-scope rules: references/incremental-restore.md.
- Startup: ChatBarApp runs bootstrap on IO before constructing repositories/preferences. MainActivity waits for backupStartupReady, blocks on errors, and defers shared intents. Alarm/accessibility/QQ components respect readiness. Commit follows successful persistent initialization.
- Sharing: domain/card/SharedImportCoordinator.kt probes eight bytes before full reads; only .cbbackup bypasses 100 MB and uses offline foreground staging. ui/shared/SharedImportHost.kt routes Backup into explicit mode/restore confirmation.

## Data semantics

- Include IDs/times, alternatives/read positions, memory histories/journals/checkpoints, RAG, moments/tasks, cards/models/settings, editor/Studio drafts/undo/guidance, design conversations, generation recipes, tag DB and preset state.
- Selected sessions require their selected character card. Deselecting a card removes its session choices. Memory/read position/chat drafts accompany a session; current images, generated voice/anchors, and SaveSlots have independent per-session toggles. Selected SaveSlots retain their own original inline/v8 package media, independent of current-chat media toggles; label this explicitly. Related models/format cards/world books are automatic dependencies; omitted global model defaults become explicit session bindings in the export only.
- Three global conversation-content toggles (images/voice/archives) appear in overview and card/session detail without expanding cards. withAllSessionContent updates only its family across selected sessions (including hidden search results) and its future/reselected default; bulk select uses withAllSessions/withSessions without resetting these defaults. Individual overrides remain available, with partial counts visible. Light preset disables all three defaults.
- Chat images off streams images/generatedImageMetadata to empty arrays without removing IDs/text/alternatives/source-turn identities. Studio history images off maps each output path to a unique OMITTED_SAVE_SLOT_IMAGE_PREFIX token, preserving recipe/seed/time; image bytes are absent unless separately referenced by another selected owner. Vibe payloads and required draft/reference assets remain with their selected owner.
- Moments image toggle controls post body images: off projects top-level imagePath/generatedImageMetadata to null, preserving avatars, text, identity, likes, times, imagePrompt/imageBrief, generation checkpoints and tasks. Omitted body refs are excluded before validation/copy/estimate; shared originals still accompany another selected owner. Light preset disables all three body/history image choices. Scope.momentsImages defaults true for earlier v2 summaries.
- Global options choose individual field groups/player/resources/credentials/catalog; only selected Keystore credentials are decrypted. Scoped REPLACE_ALL overlays selected fields, replaces selected collections, and updates selected cards/sessions by ID. Preserve unselected roots/options/media; explicitly selected empty groups clear only their corresponding data. Keep dependencies still needed by retained local records, disclose retention/deletions in preview. Legacy full archives without scope retain original complete replacement semantics with an explicit notice. Incremental matching rules remain separate. Scope uses a default session media tuple plus sparse ID overrides; old scopes remain readable. No passwords in scope.
- Scoped replacement keeps omitted chat images plus matching metadata, Moment body image/metadata, and Studio history image records from local rows of the same identity. Keep local-only message/post/history owners required by omitted media. New rows stay text/metadata-only when no local counterpart exists. Unselected voice/SaveSlot families stay local; include-empty clears them. Existing model/embedding/format/world-book dependencies are retained when their global collection option is unselected; import absent dependencies as needed.
- BackupPreferences.retainedPreferences is private merge-stage control: boot skips those local XML stores, preserving their ciphertext without decrypting unselected credentials. External archives must reject a nonempty retainedPreferences set.
- Preserve complete .cbsave and legacy inline archives, intentionally omitted-image tokens, and historical missing associations.
- Map only resource fields/legacy map keys to chatbar-backup-file tokens then destination paths. Preserve conversation/prompt text. Copy external files/content URIs into private media; keep HTTP URLs.
- API secrets/community session included by default; plaintext export warns. Destination expiration follows normal login handling. OS authorizations are rechecked; momentsAutoStartConfirmed resets only when importing Moment content/preferences, otherwise keep local confirmation. Merge model_configuration_migration.version with max(local, incoming) so unselected models/defaults do not rerun preset migrations.
- Exclude derived dictionary/index/translation caches, diagnostics, update APKs, partial downloads, hidden staging, and live process state.
- Unselected stores/runtime siblings (including mozilla/ProfileInstaller and future SDK files) are skipped without name-based exceptions. Referenced resources outside selection are copied individually to images/migrated_external; missing resources and damaged selected records still fail. Documents/draft assets preserve user file extensions; Vibe encoding responses are retained because rebuilding them needs the remote API. Regression: BackupArchiveTest and BackupDataSelectionTest.
- `BackupHistoricalResourcePolicy` permits an already absent file only for top-level moment_posts.senderAvatar. Preserve/remap the dangling reference, count it in BackupValidationReport, and show AppBackupState.warnings on export completion and before restore; no extra persisted avatar flag. Included Moment originals, current-card media, nested paths and invalid directories stay strict; errors include resource field. Regression: BackupArchiveTest and BackupDataSelectionTest. Selected Moments data migrates even when disabled.
- Forward/rollback intent is durable before renames; per-root rollback progress is restartable. Keep original preference ciphertext until commit. Missing rollback assets block startup.

## Regression map

JVM domain/backup/: path/text preservation, encrypted/plain round trips, integrity/truncation/duplicates/cancel/space/UTF-8, admission, seals and injected transaction interruptions.
Android domain/backup/: synthetic legacy/v8 packages and isolated credential preferences/key aliases.
BackupExportSelectionTest covers dependencies, three global defaults and independent choices, projected fields, deduplication, metadata-only history, UTF-8 counts and v2 round trips. BackupMergeEngineTest covers indexed/ambiguous matches, copies/media/voice, memory proofs/history, partial settings, v8 packages, cancellation, scoped replacement retaining unselected media/owners/dependencies, selected-empty groups and migration-version retention. BackupJsonStreamTest covers streamed replacement/observation, missing-field injection and strict parsing of skipped values. BackupRestoreTransactionTest covers both staging roots; BackupCredentialTransferTest covers retained XML preferences. BackupDataSelectionTest validates projected selections and missing-resource boundaries. BackupLargeStreamTest opt-in encrypted 1 GiB regression uses CHATBAR_BACKUP_LARGE_REGRESSION=1 with constant buffers.
Manual acceptance: doc/app_backup_manual_acceptance.md.
