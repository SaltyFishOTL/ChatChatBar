# ChatBar 全量迁移手动验收

## 准备

两机安装本次 APK。旧机准备模型/API 密钥、NovelAI/Fish 凭据、社区登录、聊天替代回复及阅读位置、长期记忆修订、朋友圈、原图/动画/语音/附件、编辑与工作室草稿、撤销、参考图/Vibe、生图历史及旧版/v8 会话存档。两机保留足够空间；如需保留新机数据，先导出新机备份。

导出数据清单与实际写入方见 [app_backup_data_scope.md](app_backup_data_scope.md)。只访问清单内的用户存储入口，第三方运行目录不影响导出。

## 正常迁移

1. 旧机进入「管理 → 全局设置 → 数据迁移 → 选择导出内容」，保持全选。分别导出不加密与密码加密 .cbbackup。不加密时应显示聊天和密钥提示；未保存设置先经保存/放弃流程处理。
2. 文件传到新机。在数据迁移中导入，或从文件管理器打开/分享。先经过密码/校验，再显示存档时间、版本、数量和大小；此时新机数据保持完整。
3. 确认页默认“全量覆盖”，应说明仅覆盖勾选范围、未选内容保留；先预览更新/删除数量，再确认并关闭 APP，从桌面重新打开。等待恢复；检查所选设置、模型、玩家/角色/世界书/格式卡、聊天 ID/替代回复/阅读位置、记忆修订、RAG、朋友圈及任务。
4. 检查生图参数/历史/原图/动画、语音/附件、编辑草稿、工作室草稿/撤销/参考图/Vibe、设计会话、预设记录和标签库。媒体来自新机私有目录；聊天正文和提示词中的旧机路径文字保持原样。
5. 打开旧版和 v8 会话存档。主动省略图片保持省略；历史缺失关联保留原含义。
6. 继续聊天、生图和语音生成。检查密钥可用、社区登录有效或正常要求重新登录；重新确认通知、电池、无障碍授权，朋友圈后台启用需要新机确认。

## 全量覆盖保留未勾选内容

1. 在备用机先备份基线，准备与来源同 ID 的卡/会话/消息、原图/生成参数、语音/锚点、旧版/v8 存档、朋友圈配图、生图历史原图；另留一张卡/一个会话和一条媒体记录。设置不同的主题、字号、密钥/登录、工作室草稿/撤销、标签库和朋友圈后台确认状态。
2. 来源只选该卡/会话、一项主题，关闭会话图片/语音/存档、朋友圈配图和工作室历史原图；不选其他全局设置、凭据、工作室设置。所选消息正文和动态文字改动后导出。在备用机默认全量覆盖，先预览：应明确未选内容保留，显示保留媒体/依赖的提示；预览和取消期间本机数据不变。
3. 确认重开：正文、主题等所选内容更新；字号、密钥/登录、工作室草稿/撤销、标签库和未选卡/会话保留。同 ID 消息的原图/参数、语音/锚点、存档/包，动态配图和历史原图仍可用。来源没有对应消息/动态/历史但该原记录仍承载未选媒体时，应保留其归属；新增消息没有本机原图时仍无图，本机原来仅有元数据的历史应正常更新 Seed 等元数据。继续聊天、预览原图、播放语音、读档、复用生图参数。
4. 分别验证未选整组与已选空组：不选朋友圈/历史时本机原组保留；勾选朋友圈/历史及其图片但来源确实为空时，相应组清空、预览显示删除数。会话勾选图片/语音/存档但来源为空时，仅相应组清空。不要在唯一真实副本做此验收。
5. 未选全局模型配置但所选会话自动带入同 ID 模型时，本机模型地址/密钥保持；无对应配置则新增依赖。勾选空模型/格式卡/世界书组时，仍被未选本机内容使用的依赖保留并提示。只导入主题时，联网研究偏好和朋友圈后台确认不变，模型迁移标记不降级重装预设。
6. 加密/不加密文件及早期 v2 重复上述流程；全量预览后切换增量模式需重新预览。旧 v1 无范围存档应明确提示原完整替换行为；取消时数据不变。

## 增量更新与增量导入

使用备用机和可重建验收数据；先备份本机基线，两个模式分别从同一基线开始。

1. 本机准备一张卡和会话、已生成语音与存档、朋友圈和生图历史；另留一组不会导出的记录。来源机准备对应更新和全新卡/会话；再准备不同 ID 的唯一同名卡/会话、两张重名卡，以及相同元数据/原图但路径不同的历史。
2. 来源机只勾选一项全局设置，关闭凭据与工作室设置；同一会话关闭语音/存档后导出。本机先设不同的深浅色、密钥、登录和工作室草稿。导入选择“增量更新”，预览应列新增/更新/副本数，显示唯一名称匹配和重名歧义说明。此时本机数据不变；取消预览后可正常编辑。
3. 重新预览并确认、重开。匹配的卡/会话更新，全新内容增加，未匹配本机记录和歧义目标保留；重名歧义产生副本。同一角色下会话匹配，跨角色同名会话不覆盖。不同路径但相同完整指纹的历史更新，不重复追加；相同大小但内容不同的原图不应判重。
4. 检查已勾选设置覆盖，未勾选具体设置、NovelAI/Fish 密钥、社区登录、工作室草稿/撤销和标签库保留本机内容。仅导入深浅色时，本机联网研究开关、来源和搜索数量不变；旧版设置中的兼容标记不应重置它们。匹配会话的记忆历史、阅读位置和草稿更新；未导出的语音/存档组保留，重新导出时勾选的空组则清空旧组。未选朋友圈/历史仍完整。
5. 从基线重来，选择“增量导入”：预览无更新，重复项显示副本。确认重开后原卡/会话/朋友圈/历史均完整，重复项独立存在；同名卡/会话带副本后缀。编辑或删除副本后，原件的聊天、图片、语音、存档和记忆历史仍可用。
6. 在副本中检查替代回复、阅读定位、语音锚点/音色、记忆修订和父节点覆盖；打开旧版/v8 存档并读档，复用生图历史参数。继续聊天、生图和语音生成，应归属副本。取消或中途退出预览不改原数据；切换模式后旧预览清除，必须重新预览。
7. 兼容旧 v1/早期 v2：三个模式均能进入确认。旧备份未提供逐会话媒体选择且没有语音/存档记录时，增量更新保留本机该组；全量覆盖行为仍按完整替换。确认后恢复过程中断/失败应按原事务回滚；不要在唯一真实数据副本上做中断试验。

## 失败与回归

- 清单总览显示分组、数量和图片/语音/存档三个会话总开关；设置按分类展开具体项，角色展开会话，搜索和返回保留选择。小屏/键盘打开时底部大小与下一步仍可使用。快速切换选项时估算更新，压缩实际大小允许更小；未知外部资源大小明确提示。
- 总览不展开角色卡即可分别关闭“全部会话图片”“全部会话语音”“全部会话存档”：进入详情，所有已选会话（含搜索隐藏项）相应项关闭；取消/重新选择一个会话、全选某卡会话或全选角色/会话后仍沿用各项默认。重新打开任一总开关后仅该项全部包含，其他两项不变；逐会话覆盖后总开关显示部分开启及数量。角色卡有强调底色、图标和“角色卡”标签；子会话缩进并有连接线、聊天图标和“会话”标签，同名卡/会话也能区分。
- 取消角色卡：其会话同步取消，无法单独选；重新选择角色卡后可逐个选会话。搜索筛选不应丢失其他已选会话。仅导出一张卡、一个会话，在空备用机恢复所选内容及必要依赖；已有本机未选内容保留，确认页显示按范围覆盖说明。
- 同一会话分别关闭图片、语音、存档。手机原数据仍可预览/播放/读档；存档副本中的用户图及 AI 图关联清空，文本/ID/替代回复/记忆/阅读位置/草稿完整。语音关闭时没有语音记录和音频；存档关闭时没有独立快照和包。单独打开存档选项时原存档自身媒体完整，不受当前聊天图片/语音开关影响。
- 工作室历史保留但关闭图片：空备用机的新增记录显示“仅元数据”；全量覆盖同 ID 本机历史时原图保留。仅元数据记录的查看参数/Seed、复用设置及删除可用，原图操作不可用且解释明确。混合普通图片与仅元数据记录多选删除应一次完成；混选保存应提示取消无原图记录；全屏左右切换只遍历实际原图。正常缩略图、全屏预览和生图流程回归正常。
- 勾选朋友圈但关闭“包含朋友圈图片”：估算排除仅被动态正文引用的原图，手机原动态仍完整；确认标注不含配图，空备用机的新增记录无图，全量覆盖同 ID 本机动态时配图保留。头像、文字、发布人、点赞、时间、任务及生图提示词保留。打开配图开关再导出恢复，原图正常；共有图片仍随另一所选对象保留。轻量方案默认关闭朋友圈配图。
- 只勾选深浅色等单项全局设置：对应值恢复；带选择范围的三模式均保留本机其他设置。未选密钥与登录不携带、恢复时保留本机原凭据。所选会话的关联模型/格式卡/世界书仍可使用。v1 老备份仍能校验和恢复，v2 新选择备份在旧客户端提示升级。

- 覆盖更新 APK 并重开后，再导出无密码与密码存档：已有 mozilla、ProfileInstaller 标记和其他运行目录不应阻止导出；导入确认页数量正常。备用机恢复后检查设置、登录、阅读位置、草稿、原图、Vibe、语音及存档，并继续聊天、生图和语音。
- 准备含 v8 `.cbsave` 的会话，只选该角色/会话并打开“会话存档”，关闭当前聊天图片和语音；分别导出无密码、密码 `.cbbackup`。应不再出现带 `../../.../save_slot_packages/` 的“存档路径越界”。打开导入确认核对会话与存档数量，先取消确认；原会话与原存档仍可使用。用备用机恢复后，独立存档自身图片/语音与读档正常；再回归取消导出存档、只导出旧版内联存档及独立 `.cbsave` 导出。
- 保持朋友圈关闭，使用已有旧头像缺失的历史记录导出：应成功并显示受影响记录数量；导入确认页再次显示同一提示，朋友圈开关保持关闭。备用机恢复后记录 ID、发布人、正文、点赞、时间、现存配图完整，旧缺失头像仍缺失。
- 用现存头像创建或准备一条正常朋友圈，再替换角色卡头像并保存；重开后旧朋友圈仍能显示原头像，新卡使用新头像。当前角色头像、已选包含的朋友圈原图/聊天原图/语音及附件缺失仍应失败，错误指出具体字段；关闭对应媒体选项时不校验已省略的资源。
- 错误密码、篡改/截断、缺失媒体、空间不足：明确失败，当前数据不变。来源版本较新：要求升级。
- 生成/索引/导入/会话复制中尝试导出或恢复：稍后重试，不停止现有任务。
- 打包、写目标文件、校验阶段分别取消后重试。无法清理外部不完整文件时应明确提示。
- 大于 100 MB 存档可从设置或分享导入；普通分享保留 100 MB 限制。
- 在准备恢复、目录切换、偏好恢复和初始化阶段中断后重开：提交前回滚，失败阻止进入正常页面并可重试。使用专门验收数据，不在唯一真实数据副本上做中断试验。
- 回归 .cbsave 创建/导出/导入/加载、省略图片与语音，正常启动、社区登录、朋友圈和 QQ 语音。
