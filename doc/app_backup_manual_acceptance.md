# ChatBar 全量迁移手动验收

## 准备

两机安装本次 APK。旧机准备模型/API 密钥、NovelAI/Fish 凭据、社区登录、聊天替代回复及阅读位置、长期记忆修订、朋友圈、原图/动画/语音/附件、编辑与工作室草稿、撤销、参考图/Vibe、生图历史及旧版/v8 会话存档。两机保留足够空间；如需保留新机数据，先导出新机备份。

## 正常迁移

1. 旧机进入「管理 → 全局设置 → 数据迁移」。分别导出不加密与密码加密 .cbbackup。不加密时应显示聊天和密钥提示；未保存设置先经保存/放弃流程处理。
2. 文件传到新机。在数据迁移中导入，或从文件管理器打开/分享。先经过密码/校验，再显示存档时间、版本、数量和大小；此时新机数据保持完整。
3. 确认替换全部数据，关闭 APP，从桌面重新打开。等待恢复；检查设置、模型、玩家/角色/世界书/格式卡、聊天 ID/替代回复/阅读位置、记忆修订、RAG、朋友圈及任务。
4. 检查生图参数/历史/原图/动画、语音/附件、编辑草稿、工作室草稿/撤销/参考图/Vibe、设计会话、预设记录和标签库。媒体来自新机私有目录；聊天正文和提示词中的旧机路径文字保持原样。
5. 打开旧版和 v8 会话存档。主动省略图片保持省略；历史缺失关联保留原含义。
6. 继续聊天、生图和语音生成。检查密钥可用、社区登录有效或正常要求重新登录；重新确认通知、电池、无障碍授权，朋友圈后台启用需要新机确认。

## 失败与回归

- 错误密码、篡改/截断、缺失媒体、空间不足：明确失败，当前数据不变。来源版本较新：要求升级。
- 生成/索引/导入/会话复制中尝试导出或恢复：稍后重试，不停止现有任务。
- 打包、写目标文件、校验阶段分别取消后重试。无法清理外部不完整文件时应明确提示。
- 大于 100 MB 存档可从设置或分享导入；普通分享保留 100 MB 限制。
- 在准备恢复、目录切换、偏好恢复和初始化阶段中断后重开：提交前回滚，失败阻止进入正常页面并可重试。使用专门验收数据，不在唯一真实数据副本上做中断试验。
- 回归 .cbsave 创建/导出/导入/加载、省略图片与语音，正常启动、社区登录、朋友圈和 QQ 语音。

## 当前验证边界

只编译功能和测试源码、构建 release APK。未执行自动测试、1 GiB 回归或设备诊断；跨机和故障场景按上述步骤验收。
