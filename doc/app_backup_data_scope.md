# 全量迁移存档的数据清单

导出按功能的实际持久化入口取数据。`filesDir` 是 APP 和依赖组件共用的容器，不能把其中所有内容当成用户数据；导出不枚举该容器的其他子项，也不逐个维护第三方目录排除名单。

## 选择规则

入口为「管理 → 全局设置 → 数据迁移 → 选择导出内容」。总览显示分组及数量，设置项与角色/会话进入独立详情页；支持搜索、分组全选/清空及轻量方案。默认全选可选数据。角色卡使用强调底色、角色图标及“角色卡”标签；所属会话缩进、带连接线、聊天图标及“会话”标签。

| 选择项 | 导出语义 |
| --- | --- |
| 全局设置 | 按具体设置项选择；玩家、模型配置、格式卡/世界书、密钥、社区会话、图片偏好、标签库及卡片编辑草稿也分别可选。未选凭据不解密、不携带；带选择范围的全量覆盖及增量模式均保留本机未选项 |
| 每张角色卡 | 保留卡片、人物、头像/背景、文档与所需 RAG；关联格式卡、世界书自动带入 |
| 每个会话 | 必须选择所属角色卡。保留聊天文本、替代回复、ID/时间/轮身份、会话设置、长期记忆及历史、RAG、阅读位置、聊天编辑草稿；关联模型自动带入 |
| 会话图片 | 总览及角色/会话详情页都有“全部会话图片”总开关，同步全部已选会话（含搜索隐藏项），新选/重新选择会话沿用总开关默认；不改变语音、存档选择。每个会话仍可独立覆盖，混合状态显示数量。关闭时只在导出副本中清空 `images` 和 `generatedImageMetadata`；不改正文文字、消息 ID 或手机原记录。头像、背景等设置资源继续随所属对象保留 |
| 会话语音 | 总览及详情都有“全部会话语音”开关，批量同步已选会话及新选默认；每个会话仍能覆盖。关闭时不带已生成语音记录、锚点状态和音频文件，不改变图片/存档选择 |
| 会话存档 | 总览及详情都有“全部会话存档”开关，批量同步已选会话及新选默认；每个会话仍能覆盖。保留旧版内联存档或 v8 包，包括存档自身图片、语音；与当前聊天图片/语音开关独立，界面明确提示 |
| 生图工作室设置 | 参数、当前草稿、撤销、引导检查点、参考图、Vibe 及 AI 设计会话 |
| 生图工作室历史 | 可独立关闭原图；元数据模式保留批次/图片身份、Seed、时间、提示词及配方，图片路径换为稳定且唯一的主动省略标记。新记录恢复后显示“仅元数据”，仍能复用参数及删除；全量覆盖同 ID 本机记录时，未选原图及其图片记录保留 |
| 朋友圈 | 动态及任务，不依赖展示开关。可独立选择正文配图；关闭时副本的 `imagePath`/`generatedImageMetadata` 置空，省略对应原图引用，保留头像、文字、身份、点赞、时间、生图提示词/意图、检查点及任务。手机原记录不变；同一文件被其他所选对象引用时仍保留原文件 |

取消角色卡会同时取消其会话；缺少角色卡的旧会话显示数量提示并不可选。未选择默认模型设置时，所选会话的隐式模型/格式卡绑定在副本中显式化，避免依赖新机全局默认。预设安装和兼容迁移标记保留，避免初始化重建用户已删的预设。

媒体按所选记录的字段引用收集、按路径去重，不再整目录收集未引用资产。会话存档包及标签库按各自选项单独加入。大小使用选中 JSON、去重文件和包装开销估算，在后台随选择更新；未知 content URI 大小有明确提示，最终大小随压缩和最新数据变化。正式导出会在维护锁内重新读取清单及校验投影记录。

打包所选文件时，沿用清单中明确的包内相对路径；物理文件句柄与包内名称分别传递。会话存档文件经安全校验后是规范化路径，私有目录可能仍使用系统别名，不能再对两种路径直接计算相对地址。原有目录范围、非法文件名、ZIP 条目及摘要校验保留。

轻量方案默认关闭会话图片、语音、存档、工作室历史原图及朋友圈配图；新选会话沿用三项关闭默认。三个总开关互不影响，每项均覆盖搜索隐藏的已选会话并显示部分开启数量。恢复范围摘要显示会话各类媒体数量及朋友圈是否含配图；旧 v2 摘要未记录朋友圈图片标志时默认包含。

新选择存档使用封装/清单 v2，携带紧凑范围摘要；继续读取旧 v1。旧客户端读取 v2 时提示升级。加密和流式 ZIP/校验机制不变。导入确认页默认全量覆盖，也可选择两种增量模式。

## 导入模式与匹配方案

| 模式 | 本机已有记录 | 存档没有对应本机记录 | 设置处理 |
| --- | --- | --- | --- |
| 全量覆盖（默认） | 按范围覆盖：角色卡/会话按 ID 更新，已选整组替换；未选设置、记录与媒体保留 | 添加所选内容及必要依赖 | 仅覆盖已导出设置；未选字段、凭据和工作室设置保留本机值 |
| 增量更新 | 匹配后更新对应角色卡、会话、朋友圈和生图历史；其他本机记录保留 | 添加 | 覆盖已导出的具体全局设置、凭据及工作室设置；未导出项保留本机值 |
| 增量导入 | 本机记录保留；重复内容创建独立副本 | 添加 | 与增量更新相同 |

带范围存档的三种模式均先生成预览，显示新增、更新、副本及删除数量，以及匹配、保留依赖/媒体的提示；用户再确认。切换模式需重新预览。预览期间阻止本地写入，确保确认前结果不变；取消或切换模式释放限制。确认后仍关闭、重新打开 APP，沿用启动恢复事务和回滚。

全量覆盖依据明确勾选范围，不以缺失文件、空数组、空密钥或默认设置推断用户要删除数据：

- 未选全局设置项、密钥、登录、图片偏好、标签库、玩家和工作室设置，保持本机内容；未选角色卡/会话 ID 保留。自动带入的模型、向量模型、格式卡及世界书依赖已有对应本机 ID 且未选整组时，保留本机配置；没有对应配置时添加所需依赖。
- 朋友圈、工作室历史、模型/向量模型、格式卡/世界书、卡片编辑草稿、玩家和标签库等已选整组按范围替换，选中但实际为空可清空该组；仍被保留内容引用的依赖会留下并提示，避免破坏未选会话。已选会话的聊天、记忆历史、阅读位置和草稿整体覆盖，语音/存档组由各自选项决定。
- 会话图片未选：同会话、同消息 ID 的本机 `images`/`generatedImageMetadata` 保留，正文等所选字段更新。语音/存档未选：保留本机记录、锚点、音频与包。来源没有对应消息时，仍被未选图片或语音使用的本机消息保留，避免媒体失去归属。
- 朋友圈配图未选：同动态 ID 的本机图片与生成参数保留；工作室原图未选：同历史 ID 的本机原图记录及原文件保留。来源未包含但仍承载这些未选原图的本机动态/历史也保留，并在预览提示。没有本机对应原图的新记录仍按无图或仅元数据恢复；本来就仅有元数据的本机历史正常更新 Seed 等所选元数据，不借用其他记录的图片。
- 原始媒体按原字节复制，旧媒体字段流式暂存后注入，不把消息全文、生图历史或媒体装入内存。已选图片但为空的记录仍清空对应图片字段；已选且为空的语音/存档组仍清空旧组。

旧 v1 存档没有勾选范围，原版也没有选择导出；其全量恢复保持原完整替换行为，并在确认页明确说明。不能从旧文件的空值推断不存在的选择。

增量更新采用分层匹配，避免反复读取全部原图；全量覆盖仅按 ID 定位记录：

1. 优先同类型稳定 ID。角色卡、模型、格式卡、世界书再查唯一规范化名称（去首尾空白、Unicode NFKC、统一大小写）；会话名称只在映射后的所属角色卡内查找。名称重复、多个导入记录争用目标等歧义均保留本机记录、创建副本，不猜测覆盖。
2. 无 ID 匹配的朋友圈、生图历史及任务，先按流式 JSON 元数据 SHA-256 建索引、筛候选，再对候选引用的原始媒体计算完整 SHA-256 并比较完整指纹。同一文件只计算一次。忽略根 ID、更新时间、排版空白和机器路径差异，保留正文、创建时间、配方及其他字段；不用文件名、大小或感知哈希判重。JSON 属性顺序不同可能导致安全的额外添加，不会据此误覆盖。
3. 增量导入为所有导入根记录分配独立 ID；重名对象使用“（副本）”后缀。消息、嵌套人物、文档、世界书条目、记忆及修订、RAG、语音、草稿和存档关联同步重绑。来源轮身份、替代回复版本和语音片段锚点在新会话/消息命名空间内保持原值。新媒体进入独立私有子目录，后续编辑/删除副本不改原件；远程 URL 和 Fish 声音库标识保持原值。

增量更新已匹配会话时，聊天、会话设置、长期记忆及修订、阅读位置、RAG、聊天草稿作为整体替换；语音和会话存档只在导出时选中该项才替换，未选则保留本机该组。选中但组内为空表示清空原组。增量模式沿用导出图片投影；全量覆盖采用上面的未选媒体保留规则。未匹配的本机会话保留。

旧版联网研究设置在两端分别按正常升级规则解释后，再覆盖所选字段；不会用存档的兼容版本标记重置本机未选的研究来源、开关或搜索数量。

会话媒体范围采用一组默认图片/语音/存档标志加少量会话 ID 例外，避免全选时把所有 ID 放入封装头。早期 v2/v1 未记录逐会话标志时，增量更新根据实际存在的语音/存档记录判断包含；完全不存在的组保守保留本机，无法区分“省略”与“选中但为空”。v1 无范围摘要时，设置与工作室设置按已导出处理。

预览在独立暂存区复制本机与存档数据、完成路径映射和校验，需容纳恢复树及事务额外空间；失败不写本机用户数据。`incoming` 保存已校验存档，`prepared` 保存按范围恢复或增量合并的完整树，持久事务日志记录所选树；仅旧版无范围全量覆盖直接使用 `incoming`。未选凭据通过暂存偏好标志保留原 XML 密文，不解密本机凭据；此保留标志禁止出现在外部存档。恢复不调用模型。记忆父节点证明随新子节点 ID 重算，叶节点轮身份和来源指纹保留；预设已见版本及模型迁移版本合并取最高值，避免重新安装或重置未选配置。只有导入朋友圈内容/偏好时重置其后台启用确认，未选朋友圈时保留本机确认。

## 结构化用户数据

`BackupDataRegistry.entitySerializers` 集中登记以下 40 种现用、兼容或持久恢复记录。读取 `entities/<类型>.json` 单例及 `entities/<类型>/<ID>.json` 集合中的原始文件，不经会跳过损坏记录的仓库读取方法。

| 用户数据 | 已核对的持久类型 | 写入方 |
| --- | --- | --- |
| 全局设置、玩家信息 | `app_settings`、`player_setting` | `SettingsRepository` |
| 角色卡、格式卡、世界书 | `character_cards`、`format_cards`、`world_books` | 对应卡片仓库 |
| 模型、API 密钥、向量模型配置 | `model_configs`、`embedding_configs`、`embedding_model_config`、旧版 `retrieval_model_config` | `ModelRepository`，旧版配置恢复后沿用正常升级迁移 |
| 会话、消息、替代回复、顺序、草稿、阅读位置 | `chat_sessions`、`chat_messages`、`chat_message_indexes`、`chat_message_order_backups`、`chat_drafts`、`chat_scroll_positions` | `ChatRepository` |
| 长期记忆、修订、提交及检查点、RAG 向量 | `memory_nodes`、`memory_states`、`memory_tier_revisions`、`memory_compression_transactions`、`memory_commits`、`memory_commit_journals`、`vector_chunks` | `MemoryRepository`、`RagRepository` |

| 朋友圈、持久任务 | `moment_posts`、`moment_tasks` | `MomentRepository` |

## 原始资源与偏好

下表列出资源所属路径；新选择导出按关联取文件，不代表整目录都被打包。

| 内容 | 持久路径或偏好 | 选择理由 |
| --- | --- | --- |
| 头像、背景、聊天原图、动画、生成历史原图、参考图、引导图、截图、图像处理结果及 Vibe 编码响应 | `images/` | 已核对卡片导入、编辑、聊天、生图和图片处理的写入方；属于用户资产。Vibe 响应需远程 API 才能再生成，保留已付出的编码进度 |
| 已生成语音 | `audio/`，当前语音存储写入 `audio/generated/` | 保留原音频字节；音色试听保存在 `cacheDir`，不导出 |
| 附件、编辑草稿的媒体和文档 | `documents/`、`draft_assets/` | 保留原文件，包括用户的 `.tmp`、`.backup` 等文件名；关联路径按字段迁移 |
| 会话存档包 | `save_slot_packages/` | 导出直接复制 v8 原包；按范围覆盖/增量恢复流式重写已选包的内部身份/关联及大小，媒体原字节不重编码；未选的本机包原样保留 |
| 大型 Vibe 持久载荷 | `novelai-vibe-payloads/` | 草稿、撤销、生图配方按摘要引用；保留原载荷并校验摘要 |
| 已安装标签库 | `danbooru_catalog/tag.sqlite`、`danbooru_catalog/catalog.json` | 固定选择数据库和清单；不带入下载残留。校验完整性、文件大小和 SQLite 数据库 |
| NovelAI、Fish Audio 凭据 | `novelai_credentials`、`fish_audio_credentials` | 读取明文语义，恢复时用新机 Keystore 重新加密；无法解密时拒绝完整导出 |
| 社区登录、图片处理偏好 | `community_session`、`image_mask_preferences` | 迁移登录会话、笔刷大小和类型；失效登录沿用正常重新登录流程 |

用户记录仍引用清单外的本地文件或 content URI 时，只把所引用的文件复制到存档的 `images/migrated_external/`。不导出该文件所在的其他目录或兄弟文件；远程 URL 保持原样。

## 不选择的数据与错误边界

- `mozilla`、ProfileInstaller 标记、其他未登记的根目录或文件：不扫描、不导出，不因出现新名字阻止迁移。
- 未登记的实体类型、翻译缓存、词典及补全索引、诊断日志、更新 APK、分享暂存、临时下载、进程状态：不导出。
- 已登记媒体目录的隐藏暂存、`.part`、`.tmp`、`.backup` 写入残留不主动收集；用户文档和草稿文件保留扩展名。任何被用户记录引用但未主动收集的真实资源仍单独复制。
- 已选择的记录格式损坏、目录不可读、原图/语音/附件等必需资源缺失、凭据无法解密、路径越界、空间不足：明确失败。
- 唯一新增的历史例外是 `moment_posts` 顶层 `senderAvatar`：旧头像文件已经不存在时，保留并迁移其缺失引用，在导出完成和恢复确认页说明受影响记录数量。不会清空朋友圈、替换人物身份、丢弃点赞/时间或伪造头像文件；已选择包含的真实配图和当前角色卡的头像仍须存在。主动省略的配图不参与资源存在性校验。指向目录等无效资源不适用此例外。
- 关闭朋友圈只停用展示/生成；选择朋友圈导出时，旧朋友圈和任务仍迁移。保存或删除角色卡统一保护朋友圈历史仍引用的头像、配图，修复旧头像被编辑清理误删的来源。
- 导入仍严格检查格式、版本、校验清单、所有实体类型及资源关联；未知类型不会被悄悄恢复。旧版 v1 存档的路径范围保持兼容，恢复事务不改动清单外的 SDK 根目录。

新增持久用户数据时，在集中注册表登记序列化器或资源入口，并在选择策略登记其所属选项、对象依赖，再维护此清单。无需登记依赖组件的运行目录。
